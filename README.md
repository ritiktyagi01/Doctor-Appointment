## 📌 Overview

The **Doctor Appointment Booking System** is a full-stack web application built using the MERN stack. It allows patients to book appointments with doctors, manage schedules, and handle profile updates in a secure and structured way.

This project demonstrates:
- RESTful API architecture
- Role-based authentication
- State management using Context API
- Secure backend integration
- Cloud-based image storage

---

## 🚀 Features

### 👨‍⚕️ Doctor Panel
- View and edit profile
- Manage appointment slots
- Update availability
- View booked appointments

### 👤 Patient Panel
- Browse doctors
- Book appointments
- View booking history
- Secure login authentication

### 🔐 Authentication
- Token-based authentication
- Secure middleware protection
- Role-based access control

### ☁️ Cloud Integration
- Image upload using Cloudinary
- Optimized media delivery
